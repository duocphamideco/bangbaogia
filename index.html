⚙️ Cài đặt Báo giá IDECO

Nhập mật khẩu cài đặt

Chỉ cần nhập mật khẩu quản trị để mở phần cập nhật dữ liệu và thông tin hiển thị.

Lưu ý: đây là ứng dụng HTML tĩnh. Mật khẩu này giúp khóa giao diện cài đặt; nếu cần mức bảo mật cao hơn có thể nâng cấp thêm Firebase Authentication/Cloud Function sau.
🔓 Đã mở cài đặt quản trị.
1. Chọn một hoặc nhiều file ExcelCó thể chọn nhiều file cùng lúc, hoặc bổ sung file mới vào lần sau.
2. Lưu bổ sung lên FirebaseFile mới được thêm vào danh sách, không ghi đè các file đã lưu trước đó.
3. Quản lý từng fileMỗi file có nút Xóa riêng. Xóa file không làm mất các file còn lại.
4. Đồng bộ giao diệnGộp dữ liệu của tất cả file đang lưu rồi đưa ra giao diện khách hàng.
Upload một hoặc nhiều bảng báo giá Excel (.xlsx)

Các file cần dùng cùng format cột IDECO: Mã SP, Tên thuốc, Hoạt chất, Hàm lượng, Công dụng, Quy cách, NSX, Xuất xứ, Giá, CK ≥6, Giá ≥6, CK ≥12, Giá ≥12, Nhóm điều trị. File upload sau sẽ nối tiếp dữ liệu của các file đang lưu.

Có thể chọn nhiều file cùng lúc. Nếu sản phẩm trùng mã SP, file được upload sau hơn sẽ được ưu tiên khi đồng bộ để tránh hiện trùng sản phẩm.
Chưa chọn file mới. Dữ liệu tích hợp sẵn hiện có 0 sản phẩm.
Chưa kiểm tra danh sách file Excel đã lưu trên Firebase.

Mỗi file đã lưu sẽ xuất hiện trong danh sách phía trên với nút 🗑 Xóa file riêng. Sau khi thêm hoặc xóa file, bấm Đồng bộ tất cả ra giao diện để cập nhật danh mục khách hàng. Nếu xóa hết các file rồi đồng bộ, giao diện sẽ chuyển sang trạng thái chờ bảng giá mới.
