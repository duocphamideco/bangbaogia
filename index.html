⚙️ Cài đặt Báo giá IDECO

Nhập mật khẩu cài đặt

Chỉ cần nhập mật khẩu quản trị để mở phần cập nhật dữ liệu và thông tin hiển thị.

Lưu ý: đây là ứng dụng HTML tĩnh. Mật khẩu này giúp khóa giao diện cài đặt; nếu cần mức bảo mật cao hơn có thể nâng cấp thêm Firebase Authentication/Cloud Function sau.
🔓 Đã mở cài đặt quản trị.
1. Chọn file ExcelĐọc và kiểm tra dữ liệu trước khi lưu.
2. Lưu dữ liệu ExcelLưu bản dữ liệu chờ vào Firebase để mở máy khác vẫn thấy.
3. Đồng bộ giao diệnChỉ khi bấm Đồng bộ thì bảng giá khách hàng mới thay đổi.
Upload bảng báo giá Excel (.xlsx)

Nhận các cột: Mã SP, Tên thuốc, Hoạt chất, Hàm lượng, Công dụng, Quy cách, NSX, Xuất xứ, Giá, CK ≥6, Giá ≥6, CK ≥12, Giá ≥12, Nhóm điều trị.

Chưa chọn file mới. Dữ liệu tích hợp sẵn hiện có 0 sản phẩm.
Chưa kiểm tra dữ liệu Excel đã lưu trên Firebase.

“Xóa toàn bộ dữ liệu bảng giá” sẽ xóa cả dữ liệu Excel đang chờ và bảng giá đang hiển thị trên giao diện khách hàng. Giao diện sẽ chuyển sang trạng thái “Đang chờ bảng giá mới” cho đến khi anh upload Excel mới, bấm Lưu dữ liệu Excel rồi Đồng bộ ra giao diện.
